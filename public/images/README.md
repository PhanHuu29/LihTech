# Thư mục ảnh LihTech by LihLabs

Đổi ảnh bằng cách sửa đường dẫn trong `src/lib/images.ts`:
- đặt file mới vào thư mục này rồi trỏ tới `'/images/ten-file.jpg'`, hoặc
- dùng link ngoài `'https://…'`.

Hoặc ghi đè file cùng tên (ví dụ `cover.svg`) để không phải sửa code.
Logo chính đang dùng: `logo-lihtech-horizontal.png` (header/footer) và `logo-lihtech-square.png` (favicon/nhận diện). Kích thước gợi ý cho cover là 1600×1000; icon dịch vụ 256×256; icon mạng xã hội 96×96.

Favicon nằm tại `public/favicon.png`.
